## Connect your AI assistant

You do this once per assistant. In Claude, connect from the Claude directory in one click. Every other assistant uses this URL:

```text
https://mcp.paperguide.ai/mcp
```

Pick your assistant and follow the steps.

<Tabs>
  <Tab title="Claude">
    <Steps>
      <Step title="Open Paperguide in the Claude directory" icon="external-link" title-type="p">
        Go to [claude.ai/directory/paperguide](https://claude.ai/directory/paperguide), or search for Paperguide in Claude's connector directory.
      </Step>
      <Step title="Connect" icon="plug" title-type="p">
        Click **Connect**.
      </Step>
      <Step title="Sign in" icon="log-in" title-type="p">
        Sign in to Paperguide when the window opens. If you belong to an organization, choose which account pays for this assistant.
      </Step>
    </Steps>

    Paperguide then works in Claude on the web, desktop and mobile. For Claude Code, use the **Claude Code** tab.

    <Callout kind="info" collapsed="false">
      On a Claude Team or Enterprise plan, an owner of your Claude organization may need to add Paperguide before you can connect.
    </Callout>

    <Expandable title="Manual setup" default-open="false">
      If you cannot use the directory listing, add Paperguide as a custom connector instead:

      1. Go to **Settings → Connectors → Add custom connector**.
      2. Name it `Paperguide` and paste `https://mcp.paperguide.ai/mcp`. Leave the OAuth client ID and secret empty.
      3. Click **Connect** and sign in to Paperguide.
    </Expandable>
  </Tab>

  <Tab title="ChatGPT">
    <Steps>
      <Step title="Open Apps & Connectors" icon="settings" title-type="p">
        Go to **Settings → Apps & Connectors**. Turn on developer mode if ChatGPT asks for it.
      </Step>
      <Step title="Add Paperguide" icon="plus" title-type="p">
        Add a custom remote MCP server and paste the URL above.
      </Step>
      <Step title="Sign in" icon="log-in" title-type="p">
        Sign in to Paperguide when the browser window opens. If you belong to an organization, choose which account pays for this assistant.
      </Step>
    </Steps>

    <Callout kind="info" collapsed="false">
      Custom connectors need a paid ChatGPT plan.
    </Callout>

    <Callout kind="alert" collapsed="false">
      In ordinary chat, ChatGPT uses Paperguide results but does not show them as citations. Citations appear in Deep Research: select Paperguide as a source before you start.
    </Callout>
  </Tab>

  <Tab title="Cursor">
    <Steps>
      <Step title="Open MCP settings" icon="settings" title-type="p">
        Go to **Settings → Tools & MCP → New MCP Server**.
      </Step>
      <Step title="Add the server" icon="plus" title-type="p">
        ```json
        {
          "mcpServers": {
            "Paperguide": {
              "url": "https://mcp.paperguide.ai/mcp"
            }
          }
        }
        ```
      </Step>
      <Step title="Sign in" icon="log-in" title-type="p">
        Sign in to Paperguide when prompted.
      </Step>
    </Steps>

    <Callout kind="info" collapsed="false">
      Older Cursor versions cannot connect to remote servers. Set `command` to `npx` and `args` to `["-y", "mcp-remote@latest", "https://mcp.paperguide.ai/mcp"]` instead.
    </Callout>
  </Tab>

  <Tab title="VS Code">
    <Steps>
      <Step title="Add the server" icon="plus" title-type="p">
        Add this to your MCP configuration:

        ```json
        {
          "servers": {
            "Paperguide": {
              "url": "https://mcp.paperguide.ai/mcp"
            }
          },
          "inputs": []
        }
        ```
      </Step>
      <Step title="Enable the tools" icon="check-circle" title-type="p">
        In the chat panel, open **+ → Tools** and enable Paperguide.
      </Step>
      <Step title="Sign in" icon="log-in" title-type="p">
        Sign in to Paperguide when prompted. If you belong to an organization, choose which account pays for this assistant.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Windsurf">
    <Steps>
      <Step title="Open MCP settings" icon="settings" title-type="p">
        Go to **Settings → Cascade → MCP Servers**, or edit the config file.
      </Step>
      <Step title="Add the server" icon="plus" title-type="p">
        ```json
        {
          "mcpServers": {
            "paperguide": {
              "serverUrl": "https://mcp.paperguide.ai/mcp"
            }
          }
        }
        ```
      </Step>
    </Steps>
  </Tab>

  <Tab title="Claude Code">
    <Steps>
      <Step title="Add the server" icon="terminal" title-type="p">
        ```bash
        claude mcp add --transport http paperguide https://mcp.paperguide.ai/mcp
        ```
      </Step>
      <Step title="Sign in" icon="log-in" title-type="p">
        Run `/mcp` in a session and sign in to Paperguide.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Codex">
    <Steps>
      <Step title="Add the server" icon="terminal" title-type="p">
        ```bash
        codex mcp add paperguide --url https://mcp.paperguide.ai/mcp
        ```
      </Step>
      <Step title="Sign in" icon="log-in" title-type="p">
        ```bash
        codex mcp login paperguide
        ```
      </Step>
    </Steps>
  </Tab>

  <Tab title="Other">
    Add `https://mcp.paperguide.ai/mcp` as a remote MCP server over HTTP. Assistants that support MCP sign-in open a browser window for you to sign in to Paperguide.
  </Tab>
</Tabs>

## Manage connections

See every connected assistant at **Settings → MCP** in Paperguide.

- **Disconnect** removes the assistant's access immediately. Reconnect it at any time.
- **Reconnect** asks again which account pays, if you belong to an organization.
- Several entries with the same name are normal. Each connection is separate and can be removed on its own.

## Common questions

<ExpandableGroup>
  <Expandable title="I don't see Paperguide in my assistant">
    Reconnect the assistant. New Paperguide features appear only after you reconnect. In Claude Code, run `/mcp` to reconnect.
  </Expandable>
  <Expandable title="Claude does not use Paperguide in a chat">
    Connectors can be turned off for a single chat. Open the tools menu in the message box and make sure Paperguide is turned on. You can also ask for it by name, for example "Use Paperguide to find papers on…".
  </Expandable>
  <Expandable title="Claude asks me to connect or sign in again">
    Sign in with your Paperguide account when the window opens. If Claude keeps asking, disconnect Paperguide in Claude's connector settings and connect it again. Check that it was not disconnected at **Settings → MCP** in Paperguide.
  </Expandable>
  <Expandable title="Which account pays for my credits?">
    The account you chose when you connected: your personal plan, or your organization's shared credits. To change it, disconnect the assistant and connect again. See [Credits](/mcp/credits#organization-billing).
  </Expandable>
  <Expandable title="My assistant asks which library to use">
    Your organization has more than one reference manager library. Tell your assistant which one, or name it in your request, for example "in the Lab Shared library".
  </Expandable>
  <Expandable title="My assistant says I am out of credits">
    The account you chose when connecting has used its AI credits for this month. See [Credits](/mcp/credits) for what costs credits and when they reset.
  </Expandable>
</ExpandableGroup>
