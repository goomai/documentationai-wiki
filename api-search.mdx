## Endpoint overview

Search academic papers with keyword and semantic matching. Add query parameters to filter by year, citations, open access, source, field of study, publication type, language, and journal quality.

<Callout kind="info">

Add your API key to the `x-api-key` header on every request.

```bash
x-api-key: pg_api_your_key_here
```

Create API keys in **Settings > API Keys** in Paperguide.

</Callout>

## Method and path

```bash
GET https://api.paperguide.ai/v1/search
```

## Query parameters

<ParamField query="query" param-type="string" required="true">

Search text, 1 to 500 characters.

</ParamField>

<ParamField query="year_min" param-type="integer" required="false">

Earliest publication year to include.

</ParamField>

<ParamField query="year_max" param-type="integer" required="false">

Latest publication year to include.

</ParamField>

<ParamField query="min_citations" param-type="integer" required="false">

Minimum citation count.

</ParamField>

<ParamField query="open_access" param-type="boolean" required="false">

Set `true` for open-access papers only, or `false` to exclude them.

</ParamField>

<ParamField query="has_pdf" param-type="boolean" required="false">

Set `true` for papers with a PDF only, or `false` for papers without one.

</ParamField>

<ParamField query="language" param-type="string" required="false">

Two-letter ISO 639-1 language code, such as `en` or `de`.

</ParamField>

<ParamField query="sources" param-type="string" required="false">

Comma-separated list of sources: `openalex`, `semantic_scholar`, `pubmed`, `arxiv`. Omit it, or use `all`, to search every source.

</ParamField>

<ParamField query="fields" param-type="string" required="false">

Comma-separated field-of-study IDs, such as `17,27`. See [Field-of-study IDs](#field-of-study-ids).

</ParamField>

<ParamField query="types" param-type="string" required="false">

Comma-separated publication types: `article`, `preprint`, `book`, `review`, `report`, `dissertation`, `conference-paper`, `other`.

</ParamField>

<ParamField query="journal_quartile" param-type="integer" required="false" enum="1,2,3,4">

Lowest SJR journal quartile to include. `1` returns Q1 journals only, `2` returns Q1 and Q2, and so on.

</ParamField>

<ParamField query="min_snip" param-type="number" required="false">

Minimum journal SNIP score. Papers without a SNIP score are left out.

</ParamField>

<ParamField query="min_sjr" param-type="number" required="false">

Minimum journal SJR score. Papers without an SJR score are left out.

</ParamField>

<ParamField query="issn" param-type="string" required="false">

Linking ISSN (ISSN-L) of a journal, to return papers from that journal only.

</ParamField>

<ParamField query="page" param-type="integer" required="false">

Page number, 1 to 20. Default is `1`.

</ParamField>

<ParamField query="limit" param-type="integer" required="false">

Results per page, 1 to 50. Default is `10`.

</ParamField>

## Request example

This example searches for computer science papers about retrieval-augmented generation published from 2020 to 2024, with at least 50 citations.

<Request>
```bash
curl --request GET \
  --url "https://api.paperguide.ai/v1/search?query=retrieval%20augmented%20generation&fields=17&year_min=2020&year_max=2024&min_citations=50&limit=10" \
  --header "x-api-key: pg_api_your_key_here"
```
</Request>

## Response fields

<ResponseField name="results" field-type="array" required="true">

Matching papers for this page.

</ResponseField>

<ResponseField name="total" field-type="integer" required="true">

Results found up to and including this page. This isn't the overall number of matches. If `total` equals `page` times `limit`, the next page may have more.

</ResponseField>

<ResponseField name="page" field-type="integer" required="true">

Page number returned.

</ResponseField>

Results per page.

</ResponseField>

## Get BibTeX

There is no separate BibTeX mode. Every result includes its BibTeX entry in the `bibtex` field. Join the `bibtex` values from your results to build a `.bib` file for a reference manager or manuscript.

## Tips for better results

- Search combines keyword and semantic matching. Exact terms help keyword matching, and relevant papers that use different wording still show up through semantic matching.
- Focused queries return more precise results. Add filters such as `fields`, `year_min`, or `min_citations` to narrow a broad query.
- To get more results, increase `limit` (up to 50) or request the next `page` (up to 20).

## Error responses

| Status | Meaning |
| ------ | ------- |
| `400` | A parameter is missing or invalid, such as `limit` above 50. |
| `401` | The API key is missing, invalid, or revoked. |
| `403` | The key bills an organization you are no longer a member of. |
| `429` | You hit the rate limit or used up your monthly quota. |
| `500` | Something went wrong on our side. Try again later. |
