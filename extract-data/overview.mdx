---
title: How to use Extract Data
---
Extract Data reads your papers and fills a table: one row per paper, one column per question. Every value links to the sentence it came from, so you can check it.

<Video uid="2d0ad6cc-dbf3-4fbd-bd66-422f1e9b6969" src="https://www.youtube.com/embed/29eZn6cqVyc" render-type="iframe" width="672" height="378" controls="true" allow-full-screen="true" style="width: 672px; height: auto; cursor: pointer;" />

<Callout kind="info" collapsed="false">
  Free: up to 10 papers and 5 columns per table. Paid plans: up to 100 papers and 50 columns. Extraction uses AI credits.
</Callout>

## Create a table

<Steps>
  <Step title="Pick your papers" title-type="p">
    Go to **Extract Data → Select References**, pick papers from your Reference Manager, and click **Create table**. Only papers with a PDF attached can be selected.

    <Image src="https://blob-cdn.documentation.ai/org-32657b98-c10c-411d-8b88-f43a8010b91d/doc-f333a884-cde9-44eb-8107-3714d598a727/1795609155362-f6vi3xfcw9d-02-select-papers.jpg?fm=auto&auto=compress%2Cformat" width="1470" height="779" alt="Selecting papers for a new extraction table" />
  </Step>

  <Step title="Add your research question" title-type="p">
    Type your question and click **Suggest columns**. Paperguide suggests up to 4 columns that fit your papers. Or click **Skip** and add columns yourself.
  </Step>

  <Step title="Review the columns" title-type="p">
    Your table starts with a **Summary** column plus any suggested columns. Nothing is extracted yet, so edit, remove or add columns until the table asks what you need.

    <Image src="https://blob-cdn.documentation.ai/org-32657b98-c10c-411d-8b88-f43a8010b91d/doc-f333a884-cde9-44eb-8107-3714d598a727/1795609162721-ycr2qyufglr-04-columns-ready.jpg?fm=auto&auto=compress%2Cformat" width="1470" height="779" alt="New columns waiting for extraction, with the Extract bar above the table" />
  </Step>

  <Step title="Click Extract" title-type="p">
    Click **Extract** in the orange bar. Cells fill in as you watch. For tables with 20 or more papers, you can **Run pilot on 10 papers** first.
  </Step>
</Steps>

## Run a pilot first

A pilot extracts 10 papers so you can check the results before doing the rest. Review the values, fix any column that came back wrong, then click **Extract remaining papers**.

## Add and edit columns

Open **Manage Columns** to add a column. Pick one from **Default columns** or **Your saved columns**, or click **New column** and fill in:

- **Name**: the column header.
- **Instructions**: exactly what to extract and in what format. This decides the quality of the column.
- **Answer type**: **Free text**, **Yes / Maybe / No**, or **Pick from a list**.

<Image src="https://blob-cdn.documentation.ai/org-32657b98-c10c-411d-8b88-f43a8010b91d/doc-f333a884-cde9-44eb-8107-3714d598a727/1795609166343-qtdcq7hqdcj-05-new-column-form.jpg?fm=auto&auto=compress%2Cformat" width="1470" height="779" alt="The Create new column form" />

New and edited columns wait until you click **Extract**, so set up several and run them together. When you edit a column, only that column is re-extracted. Click **+ Save** to reuse a column in other tables.

## Check any value

Click the quote icon in a cell to see the exact sentence from the paper, highlighted in context. For Yes / Maybe / No and Pick from a list columns, click the cell itself.

<Image src="https://blob-cdn.documentation.ai/org-32657b98-c10c-411d-8b88-f43a8010b91d/doc-f333a884-cde9-44eb-8107-3714d598a727/1787127919472-0cff5pbzmu9-pasted-image-1787127918141.png?fm=auto&auto=compress%2Cformat" width="2842" height="1156" alt="The Supporting quotes panel showing a cited sentence highlighted in the paper" />

Values a paper doesn't contain are marked **Not reported**, **Not applicable** or **Unclear**, never guessed.

## Settings

In **Manage Columns → Settings**:

- **Explanations**: a short note in each cell on how the value was found. On by default.
- **Output language**: the language values are written in.

## Work with your table

| To…                         | Use                                                                              |
| --------------------------- | -------------------------------------------------------------------------------- |
| Add more papers             | **Add Papers**. New papers are extracted for your existing columns.              |
| Find, sort or narrow papers | **Search**, **Sort**, **Filters** (year, citations, Has PDF, source)             |
| Download the data           | **Export** to CSV or Excel, for all rows or selected ones                        |
| Let others see it           | **Share → Create share link**. Anyone with the link can view, no account needed. |
| Fix failed cells            | **Retry** in the banner above the table                                          |

You can also save tables from the **Research Agent** and **Literature Review** into Extract Data with **Save table**.
