## Endpoint overview

Check the plan, monthly quota, calls used this month, and per-minute rate for the quota your key draws from. For a personal key, that's your personal quota. For an organization key, it's the organization's shared quota.

<Callout kind="info">

Add your API key to the `x-api-key` header on every request. Create API keys in **Settings > API Keys** in Paperguide.

```bash
x-api-key: pg_api_your_key_here
```

</Callout>

## Method and path

```bash
GET https://api.paperguide.ai/v1/usage
```

## Request example

<Request>
```bash
curl --request GET \
  --url "https://api.paperguide.ai/v1/usage" \
  --header "x-api-key: pg_api_your_key_here"
```
</Request>

## Response example

<Response>
```json
{
  "tier": "pro",
  "organization_id": null,
  "monthly_quota": 500,
  "monthly_used": 42,
  "rate_per_minute": 30
}
```
</Response>

## Response fields

<ResponseField name="tier" field-type="string" required="true" enum="free,plus,pro,max,enterprise">

Plan that sets the quota. `max` is the Evidence plan.

</ResponseField>

<ResponseField name="organization_id" field-type="string" required="false">

Organization whose shared quota this key uses, or `null` for a personal key.

</ResponseField>

<ResponseField name="monthly_quota" field-type="integer" required="true">

Calls allowed this calendar month. `-1` means unlimited.

</ResponseField>

<ResponseField name="monthly_used" field-type="integer" required="true">

Successful calls made this calendar month, across every key that shares this quota.

</ResponseField>

<ResponseField name="rate_per_minute" field-type="integer" required="true">

Requests allowed per minute, shared across all your keys. This is `30` on every plan.

</ResponseField>

## Monthly quotas by plan

| Plan | `tier` | `monthly_quota` |
| ---- | ------ | --------------- |
| Free | `free` | `10` |
| Plus | `plus` | `100` |
| Pro | `pro` | `500` |
| Evidence | `max` | `1500` |
| Enterprise | `enterprise` | `-1` (unlimited). Contact us for access. |

For an organization key, `monthly_quota` is the plan's per-seat quota multiplied by the number of seats, shared by all members.

## How usage is counted

- Only successful calls to `/search` and `/papers/{id}` count toward `monthly_used`. Errors and calls to `/usage` don't.
- Usage resets at the start of each calendar month.
- Every request with a valid key counts toward the 30-per-minute rate limit, including calls to `/usage`.
- Once your monthly quota is used up, every endpoint returns `429 Monthly quota exceeded`, including `/usage`. The error includes `used`, `quota`, and `tier`, so you can still see where you stand.

## Error responses

| Status | Meaning |
| ------ | ------- |
| `401` | The API key is missing, invalid, or revoked. |
| `403` | The key bills an organization you are no longer a member of. Revoke it and create a new key. |
| `429` | You hit the rate limit, used up your monthly quota, or your organization has no active subscription funding API calls. |
| `500` | Something went wrong on our side. Try again later. |
